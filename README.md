# SmartBiz Frontend

Do‘kon boshqaruv tizimi — React + TypeScript

## Ishga tushirish

```bash
npm install
npm run dev
```

## Sahifalar

- `/products` — Mahsulotlar ro‘yxati
- `/products/create` — Yangi mahsulot qo‘shish
- `/orders/create` — Buyurtma yaratish
- `/statistics` — Statistika dashboard

## Papka tuzilmasi

```
frontend/
├── src/
│   ├── components/     # Umumiy komponentlar
│   ├── pages/          # Sahifalar
│   ├── services/       # API so‘rovlar
│   ├── types/          # TypeScript interfeyslar
│   ├── hooks/          # Custom hooks
│   ├── App.tsx
│   ├── main.tsx
│   └── index.css
├── index.html
├── package.json
├── tsconfig.json
└── vite.config.ts
```
